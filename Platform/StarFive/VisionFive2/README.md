# Introduction to StarFive Vision Five 2 Platform

This document provides guidelines for building UEFI firmware for Starfive Vision Five 2. Vision Five 2 is a single board computer equipped with StarFive JH-7110 quad-core CPU. StarFive Vision Five 2 UEFI is designed to use U-Boot SPL + RustSBI + UEFI firmware to boot Linux kernel.
